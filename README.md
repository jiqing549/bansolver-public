# BanSolver

免费在线的德扑分析工具集 · 主站 **[bansolver.com](https://bansolver.com)**

| 工具 | 简介 |
|---|---|
| Ban2Note 牌谱解析 | GGPoker / CoinPoker 牌谱解析：统计、All-in EV、逐动作回放、对比 GTO。解析在浏览器本地完成，支持云备份 |
| 翻后 Solver | 免费在线翻后 GTO 求解器 |
| 翻前范围表 | 多套开局/防守范围矩阵速查 |
| 翻前训练 | 基于求解树的翻前出题训练 |
| Equity 计算器 | 精确枚举的胜率计算器 |
| 人生模拟器 / 番茄钟 | 辅助工具 |

## 关于本仓库

这是 BanSolver 的**源码公开展示镜像**（快照式，手动同步），仅包含前端应用与解析器源码。

**不包含**：服务端（API / Worker）、部署与运维脚本、数据管线、内部文档。
